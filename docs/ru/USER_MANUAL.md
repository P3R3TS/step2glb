# Руководство пользователя

## step2glb — Преобразователь STEP/IGES в GLB

---

**Версия документа:** 1.0  
**Дата:** Сентябрь 2026  
**Нормативные документы:** ГОСТ 19.201-78, ГОСТ 19.701-90  

---

## 1. Общие сведения

### 1.1. Назначение

Программа **step2glb** выполняет преобразование 3D-моделей из форматов STEP и IGES в формат GLB (glTF Binary). Программа предоставляет графический интерфейс с возможностью drag-and-drop, настройкой параметров tessellation и управлением сжатием.

### 1.2. Установка

#### Запуск из исполняемого файла

1. Поместите файлы `step2glb.exe`, `step2glb.bat` и `step2glb.ini` в одну папку.
2. Запустите программу двойным щелчком по `step2glb.exe` или `step2glb.bat`.

#### Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

### 1.3. Совместимость

- Windows 7, 8, 10, 11
- Linux (GTK-based окружения)
- macOS 10.14+

+-----------------------------------------------+

+-----------------------------------------------+
|  Прогресс                                    |
|  [============================] 100%          |

### 2.2. Выбор входного файла

**Способ 1 — Кнопка Browse:**
1. Нажмите кнопку **Browse…** в секции «Входной файл».
2. Выберите файл STEP или IGES в диалоге выбора файлов.
3. Нажмите «Открыть».

**Способ 2 — Drag-and-drop:**
1. Перетащите файл STEP/IGES из проводника в зону перетаскивания.
2. Путь к файлу автоматически отобразится в поле ввода.

**Способ 3 — Путь вручную:**
Поле ввода доступно только для чтения. Используйте Browse или drag-and-drop.

### 2.3. Настройка параметров

#### Пресеты (Preset)

Быстрый выбор готовой комбинации параметров:

| Пресет | Описание | Скорость | Качество |
|--------|----------|:--------:|:--------:|
| **draft** | Черновик — максимальная скорость | ★★★★★ | ★ |
| **normal** | Обычный — баланс скорости и качества | ★★★ | ★★★ |
| **high** | Высокий — детализированная сетка | ★★ | ★★★★ |
| **ultra** | Ультра — максимальное качество | ★ | ★★★★★ |

При выборе пресета поля **Lin** и **Ang** заполняются автоматически.

#### Линейная деформация (Lin)

Максимальное расстояние между реальной поверхностью и треугольной сеткой.

- Меньше значение → больше треугольников → выше детализация
- Диапазон: 0.0001 – 10.0
- Примеры: `0.001` (ultra), `0.01` (high), `0.1` (normal), `1.0` (draft)

#### Угловая деформация (Ang)

Максимальный угол (в радианах) между нормалями смежных треугольников.

- Меньше значение → более плавные кривые
- Диапазон: 0.01 – 10.0
- Примеры: `0.1` (ultra), `0.2` (high), `0.5` (normal), `1.0` (draft)

#### Флажки

| Флажок | Вкл. | Выкл. |
|--------|------|-------|
| **Relative** | Линейная деформация — процент от длины ребра | Абсолютное расстояние в единицах модели |
| **Merge** | Все треугольники части → один меш (компактнее) | Каждая грань — отдельный примитив (больше узлов) |
| **Parallel** | Используются все ядра CPU (быстрее) | Однопоточный режим (меньше RAM) |

#### Стратегия буфера (Buffer)

Управление памятью для больших файлов:

| Режим | Описание |
|-------|----------|
| **auto** | Буфер на диск при файле >500 МБ |
| **disk** | Всегда использовать временный файл |
| **none** | Всё хранится в оперативной памяти |
| **force** | Всегда диск, даже для маленьких файлов |

#### Gzip-сжатие

При включённом флажке **Gzip** выходной файл сохраняется как `.glb.gz`. Обычно размер уменьшается на 30–70%. Большинство 3D-просмотрщиков поддерживают чтение `.glb.gz`.

### 2.4. Выбор выходного файла

1. Нажмите кнопку **Browse…** в секции «Выходной файл».
2. Укажите путь и имя файла `.glb`.
3. По умолчанию имя файла совпадает с входным файлом, но с расширением `.glb`.

### 2.5. Конвертация

1. Убедитесь, что выбраны входной и выходной файлы.
2. Настройте параметры tessellation при необходимости.
3. Нажмите кнопку **▶ Конвертировать**.
4. Наблюдайте за прогрессом в индикаторе и консоли лога.
5. По завершении в консоли отобразится итоговая информация.

### 2.6. Консоль лога

Тёмная консоль в нижней части окна отображает детальную информацию о ходе конвертации:

| Цвет | Тег | Описание |
|------|-----|----------|
| Белый | `info` | Информационные сообщения |
| Синий | `hi` | Важные сообщения (путь к файлу) |
| Серый | `dim` | Дополнительная информация |
| Зелёный | `ok` | Успешное завершение операции |
| Жёлтый | `warn` | Предупреждения |
| Красный | `err` | Ошибки |

## 3. Файлы конфигурации

### 3.1. step2glb.ini

Программа автоматически сохраняет настройки в файл `step2glb.ini` в каталоге запуска:

```ini
[main]
preset = normal
lin = 0.1
ang = 0.5
relative = false
merge = true
parallel = true
buffer = auto
compress = true
```

Настройки восстанавливаются при следующем запуске.

## 4. Решение проблем

### 4.1. «Cannot open .xyz»

Программа поддерживает только расширения `.stp`, `.step`, `.igs`, `.iges`. Убедитесь, что файл имеет правильное расширение.

### 4.2. Нет drag-and-drop

Библиотека `tkinterdnd2` не установлена:

```bash
pip install tkinterdnd2
```

Или используйте кнопку **Browse** для выбора файлов.

### 4.3. Кириллические пути

cascadio не поддерживает пути с не-ASCII символами. Программа автоматически копирует файл во временную папку. При этом в логе появится предупреждение.

### 4.4. Нехватка памяти

Для больших файлов (>500 МБ) установите стратегию буфера в режим **disk** или **force**.

### 4.5. Конвертация очень медленная

Используйте пресет **draft** для быстрой проверки. Для финального экспорта выбирайте **normal** или **high**.
